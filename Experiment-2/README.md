# Experiment 2: React Components and Routing with Vite

## 📚 Description
This experiment demonstrates building a React application using Vite as the build tool. The project implements client-side routing with React Router and showcases various reusable UI components including buttons, text fields, checkboxes, dropdowns, and rating systems.

---

## 🎯 Learning Outcomes

After completing this experiment, you will be able to:

### 1. **Set Up and Configure a React Project with Vite**
- Understand the advantages of using Vite over traditional bundlers like Webpack
- Initialize a React project using Vite's fast development server
- Configure project dependencies and manage packages using npm
- Work with Hot Module Replacement (HMR) for rapid development

### 2. **Implement Client-Side Routing with React Router**
- Set up `BrowserRouter` for enabling client-side navigation
- Define routes using `Routes` and `Route` components
- Create navigation links using the `Link` component for seamless page transitions
- Organize multi-page applications with proper route configuration

### 3. **Build Reusable Functional Components**
- Create modular and reusable React components (Button, TextField, Checkbox, Select, Rating)
- Apply the single responsibility principle in component design
- Structure components in a dedicated `/components` directory for maintainability
- Export and import components across the application effectively

### 4. **Manage Component Props and State**
- Pass data between components using props
- Handle user interactions through event handlers
- Implement controlled components for form elements (inputs, selects, checkboxes)
- Understand the flow of data in a React component hierarchy

### 5. **Apply Styling to React Components**
- Use CSS modules and external stylesheets for component styling
- Implement inline styles with JavaScript objects in JSX
- Create responsive and visually appealing user interfaces
- Organize CSS files (App.css, index.css) for scalable styling architecture
